====================================================================

[ ] 13. Encontrar fatura pendente
        mysql -u root -p dbguard -e "
        SELECT i.id as invoice_id, i.plan_name
        FROM dbguard_invoices i
        JOIN dbguard_users u ON u.id = i.user_id
        WHERE u.name LIKE '%cupper%' AND i.status = 'awaiting_payment' LIMIT 1;"

====================================================================
                      TROUBLESHOOTING
====================================================================

ERRO: "Cannot find module"
→ Solução: npm install && pm2 restart all

ERRO: "Apenas admins podem acessar"
→ Solução: Verificar token é de user com role='admin'

ERRO: Scheduler não sincroniza
→ Solução: Verificar logs (pm2 logs guardsaas)
→ Verificar se aplicação rodando (pm2 status)
→ Reiniciar aplicação (pm2 restart all)

ERRO: Endpoint retorna 404
→ Solução: Verificar se index.js tem a linha de admin
→ Verificar se arquivo admin.js existe
→ Reiniciar aplicação
