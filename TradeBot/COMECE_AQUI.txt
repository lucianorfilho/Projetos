RECURSO PRINCIPAL: DASHBOARD

O Dashboard exibe em tempo real:

  ✓ Gráfico de preços (últimas 20 velas)

================================================================================
INTERPRETANDO OS SINAIS
================================================================================

COMPRA (↑)    -> Confluência de indicadores para COMPRAR
VENDA (↓)     -> Confluência de indicadores para VENDER
AGUARDE (→)   -> Sem confluência clara, aguarde

Confiança:
  > 90%  = Sinal muito confiável
  75-90% = Sinal confiável
  50-75% = Sinal moderado
  < 50%  = Sinal fraco

Força:
  FORTE    = Múltiplos indicadores alinhados
  MODERADO = Alguns indicadores confirmam
  FRACO    = Poucos indicadores confirmam

================================================================================
TROUBLESHOOTING
================================================================================

Problema: "ModuleNotFoundError: No module named 'flask'"
Solução: pip install -r requirements.txt

Problema: "Address already in use"
Solução:
  - Feche outras instâncias do dashboard
  - Ou altere a porta em dashboard_server.py

Problema: Dashboard não carrega
Solução:
  - Abra http://localhost:5000 no navegador
  - Verifique o console (F12) para erros
  - Reinicie o servidor
